## Entries that are not shims

These names appeared in an earlier draft of this inventory. They are not methods in the codebase and are not deprecation targets:

- `AIPS_Prompt_Builder::build_prompt()` does not exist. Public prompt methods include `build_content_prompt()`, `build_excerpt_prompt()`, `build_title_prompt()`, `build_slug_prompt()`, `build_featured_image_prompt()`, and `build_prompts()`. Other `build_prompt()` methods belong to `AIPS_AI_Assistance_Service`, `AIPS_Internal_Link_Inserter_Service`, and `AIPS_WP_AI_Client_Provider`, and those are private implementation methods.
- `AIPS_DB_Migrations::migrate_history_table()` does not exist. History schema changes are private versioned steps invoked from `AIPS_DB_Migrations::check_and_run()`, including `migrate_to_2_5_0()` (datetime to unix timestamps), `migrate_to_2_8_2()` (campaign columns on history), `migrate_to_3_4_0()` (`post_type` backfill), and the `aips_history_log` index steps in `migrate_to_3_7_8()` and `migrate_to_3_7_20()`. Those steps stay while an older install can still upgrade through them.

## Removal & Deprecation Guidelines

1. **Deprecation Notice Requirement**:
   - Any class or adapter marked for deprecation must emit `_deprecated_class()` when instantiated. Use `_deprecated_constructor()` only for a deprecated constructor signature, not as a stand-in for a deprecated class. The third argument of `_deprecated_class()` is the replacement class.
   - Deprecated methods must emit `_deprecated_function()`.
   - A `class_alias()` cannot emit a deprecation notice by itself.
2. **Container Construction Guardrail**:
   - No deprecated classes should be bound into `AIPS_Container` or instantiated in core application bootstrapping.
3. **Target Removal Window**:
   - `4.0.0` is a proposed review point, not automatic permission to delete an adapter. Recheck runtime and external callers, serialized references, and supported upgrade paths before each removal. Keep historical migration steps while any supported installation may still need them.
   - A row marked **Blocked** still has a production caller. Do not schedule it for removal until that caller is gone.
